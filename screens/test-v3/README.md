## 1. الفلسفة المعمارية والتصميمية (Design Philosophy)

تم بناء الإصدار الثالث **V3** (`screens/test-v3/`) ليكون تحفة برمجية وبصرية تخاطب شريحتين رئيستين على أعلى درجات التدقيق العلمي:
1. **طالب الثانوية العامة والمتفوق المتقدم (The Scholar Persona):** بيئة دراسية واختبارية جادة، خالية من المشتتات، مدعومة بمحاكيات فيزيائية تفاعلية حية (كالحث الكهرومغناطيسي وآلة حاسبة علمية مدمجة)، مع قفل أمني مشدد (Single Hardware Binding) يضمن العدالة المطلقة.
2. **الأستاذ الجامعي ورئيس قسم الفيزياء (University Faculty / Department Chair Persona):** مركز عمليات متكامل للتحكم الأكاديمي، يتيح تحليل توزيع درجات الدفعة وفق منحنى غاوس (Gaussian Bell Curve)، صياغة الاختبارات بمعادلات LaTeX حية، وفرز عرائض نقل الأجهزة عبر رادار المطابقة البايومترية (5-Axis Hardware Radar).

## 3. الرسوم المتجهة والأصول العلمية الأصيلة (Bespoke Physics SVGs)

وفقاً لمعايير **Awwwards** الصارمة، لا يحتوي المشروع على أي صور عشوائية أو أيقونات مسبقة الصنع. كل رسم هو كود `SVG` أصيل مكتوب يدوياً ومستند إلى قوانين الفيزياء الحقيقية:

1. **`hero.html`:** مسرع الجسيمات الدوراني (Quantum Cyclotron & Dee Magnets) مع مسار انحراف لورنتز ومحاكي تجربة فاراداي الحية ($\Phi = B \cdot A \cos\theta$).
2. **`student-dashboard.html`:** الملف الحلقي الطوري (Toroidal Solenoid Magnetic Flux) وخطوط المجال المغناطيسي المغلقة.
3. **`course-viewer.html`:** راسم الإشارات الكاثودي (Cathode Ray Oscilloscope - CRO) بموجات جيبية متذبذبة وعلامة مائية مضادة للقرصنة.
4. **`exam-taking.html`:** الساق الموصلة المنزلقة على موصلين متوازيين في مجال مغناطيسي عمودي ($e.m.f = -B \ell v$).
5. **`student-results.html`:** ختم دبلومة التخرج الأكاديمي بنقوش الجيلوشيه الهندسية (Guilloche Rosette Diploma Seal).
6. **`teacher-dashboard.html`:** منحنى التوزيع الطبيعي الغاوسي (Gaussian Bell Curve) مع رادار كشف مواقع الطلاب الممتحنين.
7. **`quiz-builder.html`:** جدار القفل المشفر لمكافحة الغش (Anti-Cheat Security Enclave Ring).
8. **`student-devices.html`:** درع التشفير العتادي TPM وحلقة القفل الدوارة.
9. **`requests-management.html`:** مخطط الرادار الخماسي للمطابقة البايومترية (5-Axis Pentagon Hardware Telemetry Radar 94.2%).
10. **`blocked.html`:** بوابة حزم الليزر المتقاطعة وقفال الحظر المنيع.
11. **`login.html`:** منشور نيوتن الزجاجي وتشتت الضوء الأبيض للأطياف المرئية ($\lambda = 700\text{nm} \to 400\text{nm}$).
12. **`signup.html`:** القدمة ذات الورنية (Vernier Caliper) بدقة قياس $0.01\,\text{mm}$ مع ختم النزاهة.
13. **`error-404.html`:** التلسكوب الفلكي وسحابة الاحتمالية الكمومية لمبدأ عدم التأكد لهايزنبرج ($\Delta x \cdot \Delta p \ge \frac{\hbar}{2}$).

## 4. فيزياء الحركة والتفاعل الميكانيكي (Motion Physics & Tactile Polish)

* **ردود فعل لمسية (Emil Kowalski Physics):** كل زر وبطاقة تفاعلية مزودة بحركة ضغط ميكانيكية `:active { transform: scale(0.98); }`.
* **سلاسة الرسوم المتحركة:** حركات كهرومغناطيسية دقيقة (`@keyframes radarSweep`, `@keyframes pulseGlow`, `@keyframes waveFlow`).
* **احترام خيارات سهولة الاستخدام:** دعم كامل لـ `@media (prefers-reduced-motion: reduce)` لإيقاف الحركات فوراً للمستخدمين الذين يفضلون تقليل الحركة.
* **ثنائية اللغة الكاملة:** تبديل فوري بين العربية (RTL افتراضياً) والإنجليزية (LTR) مع حفظ الحالة محلياً في المتصفح.

## 6. التحقق والاختبار عبر Playwright MCP

تم فحص الشاشات والتأكد من:
- العمل المستقل بنسبة 100% بدون أي خادم أو حزمة برمجية (Standalone Local File Execution).
- خلو وحدة التحكم (Console) من أي أخطاء جافاسكريبت أو روابط 404 مفقودة.
- التوافق التام مع الشاشات الصغيرة (Mobile `< 640px`) والمتوسطة (Tablet `768px`) وشاشات سطح المكتب العريضة (`1440px+`).
